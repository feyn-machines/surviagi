# 开发队列隔离验收

关联：[Issue #102](https://github.com/feyn-machines/surviagi/issues/102)。验收日期：2026-11-08。

## 授权与接单入口

本项目 Feyn 仅处理网站仓库 `feyn-machines/surviagi` 的网站和系统开发工作；知识库 `feyn-machines/surviagi-knowledge` 的内容工作不授权给 Feyn。公开贡献者可独立维护知识库，标签不改变这一边界。完整贡献规则见 [CONTRIBUTING.md](../../CONTRIBUTING.md#开发队列与知识库边界)。

真实接单入口在 Feyn 程序，不在网站应用、HTTP/MCP 读取接口或 GitHub Actions：

1. `feyn goal` 将显式登记的任务及可选仓库来源存入工作区的本地目标记录。
2. Feyn 的 `github.ts/readFacts` 读取已登记任务；只有配置仓库来源时，才对该仓库执行 `is:open label:f-ready -label:f-wait` 查询。
3. `goals.ts/applyFacts` 根据该来源建立任务，`readyItems` 筛选可开始项，`tick.ts` 为选中的任务建立独立会话。正文链接不参与任务发现，依赖读取不创建任务。

本次只核查已安装实现，不修改 Feyn 全局代码。若这些入口未来需要改动，应在 Feyn 所属项目独立交付，再在本项目复验。

本地目标、会话和调度记录保持私有；本页是公开验收摘要，不携带原始记录。

## 隔离验证及结果

使用 Node 对已安装的 `readFacts` 注入内存 GitHub 响应，记录并断言其全部 GitHub 请求；不创建真实知识库任务，不更改真实标签，也不启动试验会话。分别验证当前无自动来源的显式任务表，以及仅指定网站仓库来源的读取模式。

| 场景 | 结果 |
| --- | --- |
| 无仓库来源，仅知识库存在可带 `f-ready` 的外部 Issue | 不执行标签发现查询；只读取已登记网站任务，不请求知识库 |
| 来源限定网站仓库，网站任务带 `f-ready` | 查询限于网站仓库，网站任务进入匹配结果 |
| 网站任务正文含知识库 Issue URL | 不沿链接请求知识库，不产生外部匹配项 |
| 网站任务含跨仓前置条件 | 读取依赖事实，不将依赖创建成任务；不请求知识库 Issue |
| 当前本地配置 | 断言 12 项均属网站仓库、当前目标无自动来源、active 目标无跨仓来源，全部通过 |

上述两组函数测试及配置断言全部通过。它们验证读取边界，结合 `applyFacts` 的任务创建路径检查，支持当前配置下知识库标签不能触发派单的结论。依赖接口在该实现中只投影 Issue 编号，本次不验证跨仓依赖的仓库身份或同号映射是否正确；只验证它不扩展接单范围。测试未在生产调度器上实际添加知识库 `f-ready` 标签，也不宣称进行过这类线上故障注入。

## 适用范围与维护

这是 2026-11-08 当前配置和已安装程序的验收结果，不是全局禁止任何人手动登记外仓任务的程序级 ACL。今后不能以“通用命令允许添加”为授权理由，手动添加知识库任务或把来源改为知识库；此类配置违反本项目规则。修改目标来源、显式任务或 Feyn 接单程序后，必须重新检查以上场景。

本次没有修改网站运行代码、知识库内容、Feyn 程序或两项每日调度，没有生产部署。纯文档交付检查引用、差异与公开文件门禁；不运行网站构建或数据库写入测试。
