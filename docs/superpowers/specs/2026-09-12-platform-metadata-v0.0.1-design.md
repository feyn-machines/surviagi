## 交付范围

- 全量引用 O*NET 31.0 的 23 个职业大类、1,016 个职业、18,838 条任务和工作活动关系；不把少数样例当作全量。
- 职业中文名由 AI 翻译，原名、代码和翻译状态并存。任务英文原文完整保留，未翻译的中文为空。
- 建立覆盖主要生产与服务领域的中文赛道树，逐项对照 ISIC Rev.5 的 22 个门类；这是 openaiwill 编辑目录，不冒称官方或穷尽所有商业赛道。
- “领域 → 细分赛道 → 具体工作”与“职业大类 → 职业 → 职业任务”是两个入口。节点有自己的稳定 ID，外部代码和跨目录映射分别保存；未裁决的关联保持候选，不借其自动转移能力分数。
- 对现有全部职业任务生成重要性归一化权重草案。来源重要性并非工时或就业份额；被来源标为低精度的 IM 不直接使用，缺值用职业内可用 IM 均值，整职业无可用值时明确等分。
- 赛道同级权重由 AI 提议，职业大类内部的职业权重在就业资料尚未接入前暂用明确标注的等分起点。权重属于父子关系，不属于节点本身。
- 事件、指标观测、进度更新都有严格字段结构；首版不虚构真实事件或能力数字，进度保留 null。初始权重是可修改的草案，不是生产世界权重。

## 数据合同

发布目录为 datasets/platform/releases/v0.0.1。JSONL 每行一条记录，JSON Schema 2020-12 随包保存。

| 集合 | 含义 |
| --- | --- |
| nodes | 自有稳定 ID、类型、中英文名称、范围与来源身份 |
| relations | 按市场或职业视图保存父子关系、顺序 |
| external_mappings | 节点到外部体系/版本/代码的关联、方法、状态和依据 |
| weights | 父子关系上的份额、方法、来源值或补值说明 |
| metric_definitions | 发布可用性、采用、测试结果、社会关注等指标定义 |
| events | 事件及发生时间、来源版本、主题关联 |
| observations | 某事件某指标的观测值、时刻、来源和归因 |
| progress_updates | 旧值、新值、触发事件、指标输入、估计方法和变化原因 |
| progress | 当前节点进度；未知为空，未覆盖不重新归一化 |
| sources | 外部来源身份、版本、URL、许可与文件哈希 |

全量来源引用作为独立 reference 集合保存，方便证明覆盖、关联和权重依据；自有赛道标签与外部体系不是强制一对一。来源版本、数据包版本、格式版本、权重方法版本与估计方法版本分开记录。

进度更新规则为“旧进度 + 新事件的指标和证据 → 按同一套方法评估 → 新进度”。可以上调、下调或不变。重复事件及相同输入不得重复形成增量；关注计数不直接换成能力百分点。页面详情展示事件，不要求“已经能做什么/仍需人做什么”的两个判断板块。

## 版本和冻结

使用 v主.次.修订，例如 v0.0.1；机器字段不带 v。每次数据包有前版标识和前版根哈希、变更分类、变更说明、精确输入版本与哈希。大版本用于不兼容结构/ID/计分含义变化，中版本用于兼容扩展或方法/权重规则升级，小版本用于同合同同方法下的事件、指标、估计和修正。

本项目把上述约束也用于 0.x 草案；这比 SemVer 对初始开发阶段的最低约束更严格。版本包一经封存不可覆盖，修改必须构建新版本。v0.0.1 是本地数据草案，版本化不等于生产发布。

manifest 列出包内每个数据/Schema/说明文件的 SHA-256，manifest.sha256 保存 manifest 自身的哈希，避免自引用。每次构建先完成临时目录及校验，再原子移动到最终版本目录；目标已存在则拒绝。

## 必须成立的校验

1. 来源数量和 ID 全量对应；没有截成样例；所有中文职业名有翻译标记。
2. 节点 ID 唯一，引用存在，分类无环；跨视图共享节点合法。
3. 同一父节点的有效权重和为 1；每条权重对应确切关系，来源量表与推导份额不混淆。
4. 0 与 null 分开；进度只允许 0–100，不能伪造初始能力数字。
5. 多对多外部映射允许；候选语义关联不自动成为计分分配关系。
6. 事件和观测均有来源，进度变更可追到输入；方法修订与能力更新分账。
7. 文件清单、行数、哈希、版本依赖一致；校验器拒绝旧版本被改写或降级版本号。
8. 全量资料保留原始来源和许可；未经确认可再分发的 ISIC 原文不复制到公开版本，只保存代码引用和自有覆盖说明。

## 当前实现边界

交付数据包、可重建来源、Schema、封装/校验命令和规范。不接通网页实时采集，不上线估计器，不把既有历史试算并入本版。BLS 三个工作簿已在本地，通过容器完整性检查；本版不把尚未解析核对的单元格当作已应用就业权重。
