## Agent 初查发现

从排序后的 54 个窗口 ID 中使用 Python `random.Random(25).sample` 随机取 12 条，逐项阅读保留全文、任务、主体、类型、结果和事实。本次是 Agent 文本审阅，不是人工审核，未把观察状态改为人工确认。样本量未达到规范建议的 50 条，也未完成无产出材料的漏抽样本，不报告人工准确率或总体召回率。

发现需要复核的具体类型：

- 同一条观察合并多个模型和不同职业任务；耗时测量被写成任务成功，原文不能支持这个结果。
- 原文仅为一般软件安装体验，没有 AI 完成具体工作的描述，却被提取为自用观察。
- 泛指产品工作流或未来准备执行，被标记为作者已经自用；需分清说明、计划与实际尝试。
- 原文分数为“超过 8”，事实只存 `8`，丢失不等式。引文命中仍不能保证数值表达正确。
- 宽泛评测任务成本或总体会话指标，应复核具体工作边界，不能直接作为完成整项工作的证据。

逐条判断及样本 ID 留本地，未公开第三方全文。这些是待确认错误类型，尚未形成新回归测试或修复，也未核实独立研究的原始报告。后续应据此补抽取回归，并在同样本上做前后比较；不能只增加词条而宣称质量改善。
